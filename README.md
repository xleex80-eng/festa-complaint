# 청사 불편민원 관리 (체험판)

청사 시설 불편민원(화장실 고장, 조명, 냉난방 등)과 시설 외 민원을 접수하고, 처리 상황과 통계를 한곳에서 관리하는 프로그램입니다.

> 체험판의 민원·기관·이름·연락처는 모두 지어낸 예시 자료입니다.

## 해결하려는 문제

- 시설불편민원 관리대장과 시설 외 민원 처리대장을 엑셀 두 파일, 분야별 여러 시트에 나눠 손으로 적었습니다.
- 미처리 건을 찾거나, 처리 기간(당일·3일 이내·3일 초과)을 업무일로 세거나, 분야별·월별 통계를 내는 데 시간이 많이 들었습니다.

## 주요 기능

| 화면 | 하는 일 |
|---|---|
| 접수 | 민원 입력, 접수번호 자동 부여, 내용 낱말로 분야 자동 추천(예: '형광등' → 전기 > 전등 > 점등불량) |
| 대장 | 두 대장 통합 조회, 구분·분야·상태·기간·검색으로 거르기, 미처리 건 바로 보기, 수정 |
| 통계 | 분야별·월별·시간대별 접수 건수, 당일 처리율, 만족도 그래프와 A4 인쇄 |
| 가져오기·내보내기 | 기존 엑셀 대장 가져오기(형식 오류 표시), 기존 양식 그대로 엑셀 내보내기, 공휴일 관리, 백업·복원 |

## 실행 방법

- 배포 주소: Local (인터넷이 안 되는 업무망 PC에서 쓰는 프로그램이라 별도 서버 없이 파일로 실행합니다)
- 실행 환경: Windows PC, Edge 또는 Chrome 브라우저. 설치할 것이 없습니다.
- 실행 방법:
  1. 이 저장소 위쪽의 초록색 [Code] → [Download ZIP]을 눌러 내려받고 압축을 풉니다.
  2. `index.html`을 더블클릭해 Edge나 Chrome으로 엽니다.
- 처음 열면 올해 예시 민원이 들어 있습니다. [접수]에서 "5층 복도 형광등 깜빡임"처럼 입력해 분류 추천을 확인해 보세요.
- 엑셀 가져오기를 시험하려면 `sample` 폴더의 가짜 대장 2개를 [가져오기·내보내기]에서 선택하세요.
- [가져오기·내보내기] → [예시 자료로 되돌리기]로 처음 상태로 돌아갑니다.

## 실행 환경과 특징

- 인터넷이 안 되는 업무망 PC에서도 쓰도록 파일 하나(약 1MB)에 모든 기능을 담았습니다.
- 입력한 자료는 그 PC의 브라우저 저장소(IndexedDB)에만 저장되고 밖으로 전송되지 않습니다(외부 통신 차단 설정 포함).
- 처리 기간은 접수 다음 날부터 주말·공휴일을 빼고 셉니다.

## 소스 구성

- `src/`: 화면(app.html, app.css), 기능(app.js), 분류표(classification.js), 그래프(viz.js), 예시 자료(demo.js)
- `vendor/exceljs.min.js`: 엑셀 읽기·쓰기 공개 라이브러리
- `build.py`: `py build.py`를 실행하면 위 파일을 합쳐 `index.html` 하나를 만듭니다.
- `tools/make_fake.py`: `sample` 폴더의 가짜 대장을 만드는 스크립트
